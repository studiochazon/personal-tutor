## Persona Tutor AI - A Cursor like application to create a custom learning path (courses)

## Features
1. Initial Prompt text (like ChatGPT)
2. A courses page 
3. Single course page
4. Single lessons page


## Tech
1. Mysql DB - tables - courses, lessons, progress
2. Svelte, Svelte kit, .jsx
3. Sveltekit API to access Mysql
